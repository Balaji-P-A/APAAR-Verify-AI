# APAAR-Verify AI brand guide

**Product name:** APAAR-Verify AI  
**Tagline:** Verify. Monitor. Govern.

| Token | Hex | Intended use |
|---|---|---|
| Primary blue | `#0B5FFF` | Primary actions, emphasis |
| Deep navy | `#0A2E63` | Headers, dark surfaces |
| Supporting blue | `#0755D9` | Links, charts |
| Cyan | `#06B6D4` | Secondary accent, focus |
| Green | `#10B981` | Positive states, identity confirmation |
| Canvas | `#F8FAFC` | Light backgrounds |
| Text | `#1E293B` | Main text |

Logo files with `-white` are intended for dark backgrounds. Use the regular lockup on white/light backgrounds.
