# APAAR-Verify AI — Rebranding Notes

This working copy has been visually and textually rebranded as **APAAR-Verify AI** for the APAAR-based student data management and verification prototype.

## What changed
- Product name, web metadata, login/header identity, PWA labels, Android launcher/app label, PDF/report branding, translations, documentation, and project color tokens.
- Replaced the previous EduSynC artwork with a new custom APAAR-Verify AI identity.
- Kept the Python package/directory `edusync/`, MongoDB database default, Android namespace `com.acadentrix.app`, and Gradle project folder `Acadentrix/` unchanged to avoid breaking imports, persisted local data, or Android identifiers.

## Important prototype limitation
This is **not an official AICTE or APAAR integration**. Validation and verification are performed against this prototype's own database unless an authorized official integration is separately implemented and approved. Use synthetic data for demos and do not represent generated records as government-verified.
